# 🏥 Backend System for Frontline Healthcare App

This Node.js-based backend system supports a healthcare Android app used by frontline health workers. It is designed for high availability, security, and offline support, with a scalable architecture that handles 2000+ RPS.

## 🚀 Tech Stack

- **Backend:** Node.js (Express)
- **Database:** PostgreSQL / DynamoDB
- **Infra:** Multi-region AWS
- **Security:** HTTPS, JWT, AES-256
- **Scalability:** Load Balancers, Auto-scaling
